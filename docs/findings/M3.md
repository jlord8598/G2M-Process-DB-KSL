**Rules implemented.**
- **`DEPARTMENT_NAME` (Q-02).** The COA `DEPARTMENT_NAME` per `ACCT_DEPT_SEGMENT`
  when that code has exactly one distinct name, otherwise null. The lookup is
  grouped to one row per code, so the join cannot fan out.
- **`IS_SUBTOTAL` (Q-05, Q-08).** `TRUE` when the `ITEM_TAG` starts `TOT`, or
  when the tag is a COA `IS_TOTAL_LINE` tag and no COA row of the tag carries
  an account or stat account. `SUBTOTAL_SOURCE` states which rule applied:
  - `ITEM_TAG prefix TOT: source rollup (owner Q-05)`
  - `COA IS_TOTAL_LINE, tag carries no account: source rollup (owner Q-05, Q-08)`
  - `COA IS_TOTAL_LINE on account-coded detail: unflagged (owner Q-08)`
  - the build 01 borderline and default texts otherwise.

  At COA level the rule selects every flagged tag except exactly `I00058`,
  `I00114` and `I00382` (query `01c7e8a7-020a-3b31-0003-4ff21bb90616`).
