## Decisions at stop 1 (owner)

- Q-01 (b): SOURCE_TABLE carries the new table name; every downstream literal (45: 24 in transformation, 21 in the seeder) and the CLAUDE.md rule text change with it. The proof does not exclude SOURCE_TABLE: old -> new via CLN_UTIL_TABLE_MAP, semantic must match on every column. Where two old tables share one new table (JW FCAST_ACT_FORECAST / FCAST_BY_PERIOD -> CLN_JW_VENICE_FIN_PL_SUMMARY; PIG PACE THIS_YEAR / NEXT_YEAR -> CLN_PIG_HOTELS_PACE_OTB_MONTHLY), any literal that told them apart uses the merge column instead: SOURCE_OBJECT (JW) and PACE_YEAR (PIG). The owner named STAY_YEAR_SCOPE for PIG; no such column exists in the schema; the view and the table use PACE_YEAR (and SOURCE_OBJECT), so PACE_YEAR is used.
- Q-02: the HERSHA view filters are approved as a one-build exception to invariant 1, written as each view's own WHERE and commented as temporary. Logged: N-36 (3,056 budget-only rows in CLN_HERSHA_FIN_PL_MONTHLY), N-37 (1,798 non-preferred rows in CLN_HERSHA_OPS_STATS_MONTHLY).
