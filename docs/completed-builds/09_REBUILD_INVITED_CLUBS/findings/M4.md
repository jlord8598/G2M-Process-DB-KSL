## What changed

**`SPROC_XREF_ACCOUNT_CLASSIFICATION`, INVITED_CLUBS branch.**
- **New CTE `mtb`:** META `TIME_BALANCE`, primary (non-shared) instance, from
  `STG_INVITED_CLUBS_META_ACCOUNT`, one row per member.
- **New column `r_class`**, applied after STATISTIC, in this order:
  - IND: name starts `Ind` -> Unclassified.
  - ACE: Adjusted Cash EBITDA -> Unclassified.
  - PLAN: site starts `Plan ` -> Unclassified.
  - DUES: META expense dues roll-forward -> Statistic.
  - KPI: META revenue, not an A-code -> Statistic.
  - A5REV: META revenue A-code outside A4 -> Below the Line / OI/E.
- **DUES / KPI columns:** H2 is the member name, METRIC_UNIT `currency`, and
  AGGREGATION_TYPE `STOCK` for `BegBase_*` / `EndBase_*`, else `FLOW` (META
  flow).
- **SEED_SOURCE** names the rule and its decision.

**`scripts/reseed_build09.sql`.** The branch's own USING block, copied by a
generator, as a `MERGE ... when matched` only.
- It touches only rows that are UNREVIEWED and differ.
- It sets only H1-H5, section, balance, sign, METRIC_UNIT, AGGREGATION_TYPE
  and SEED_SOURCE.

**`SPROC_XREF_INVITED_CLUBS_MAIN`** is restored from git.
