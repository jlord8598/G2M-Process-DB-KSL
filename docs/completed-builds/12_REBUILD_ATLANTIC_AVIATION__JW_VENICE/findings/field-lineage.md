# Field lineage (build 12 changes): where does each column come from?

Columns not listed are as in build 11's field-lineage.md (archived) for JW_VENICE and ATLANTIC_AVIATION, and unchanged for every other lane.

| Column | Lane / table | Source |
|---|---|---|
| CURRENCY_CODE | all six SEM tables, every lane | literal in the lane block of SPROC_SEM_AI_* (Q-10): USD; EUR (JW_VENICE); MIXED (BEAUMIER); UNCONFIRMED (ALTERRA) |
| SOURCE_UNIT_SCALE, SOURCE_UNIT_SCALE_SOURCE | STG_ATLANTIC_AVIATION_OC_DATA, XFRM_ATLANTIC_AVIATION_* | SPROC_STG_ATLANTIC_AVIATION_OC_DATA, from CLN LINE_ITEM (1 for Landings / Trips / MPG, else 1000) |
| SOURCE_AMOUNT, STAT_VALUE, VALUE | ATLANTIC_AVIATION, XFRM and SEM | staged value x SOURCE_UNIT_SCALE (SPROC_XFRM_ATLANTIC_AVIATION); STG keeps CLN ACTUAL_ / FORECAST_ / BUDGET_AMOUNT as booked |
| SOURCE_SITE_CODE / ASSET_NAME | JW MONTHLY_PL_DEPT | CLN PROPERTY_NAME |
| DEPARTMENT | JW MONTHLY_PL_DEPT | CLN DEPARTMENT (the sheet); raw also as SRC_DEPARTMENT |
| ACCOUNT_KEY / SOURCE_ITEM_ID / ACCOUNT_DESC | JW MONTHLY_PL_DEPT | CLN LINE_ITEM |
| RECORD_TYPE, RECORD_TYPE_SOURCE | JW MONTHLY_PL_DEPT | derived from LINE_ITEM (98xxxx, 4-digit codes, named statistics -> STATISTIC) |
| IS_SUBTOTAL, SUBTOTAL_SOURCE | JW MONTHLY_PL_DEPT | derived from LINE_ITEM (named money lines; 4 named hours lines); raw IS_SUBTOTAL as SRC_IS_SUBTOTAL |
| PERIOD_END | JW MONTHLY_PL_DEPT | CLN PERIOD_DATE |
| SCENARIO | JW MONTHLY_PL_DEPT | ACTUAL branch: CLN ACTUAL_SOURCE_SCENARIO (ACTUAL, LAST YEAR); BUDGET branch: BUDGET_AMOUNT (D-45) |
| SOURCE_AMOUNT / STAT_VALUE | JW MONTHLY_PL_DEPT | CLN ACTUAL_AMOUNT or BUDGET_AMOUNT by branch, as booked |
| SOURCE_LINE_KEY | JW MONTHLY_PL_DEPT | DEPARTMENT / LINE_ORDER / LINE_ITEM / PERIOD_DATE / PERIOD_TYPE / branch |
| UNKNOWN_REASON DUPLICATE_DETAIL | JW_VENICE | SPROC_XFRM_JW_VENICE d48_loses (Q-02, Q-03, Q-09, Q-11) |
| H1-H5, P_L_SECTION, NORMAL_BALANCE, VALUE_SIGN | JW MONTHLY_PL_DEPT keys | seeder JW branch, account blocks (Q-04) |
