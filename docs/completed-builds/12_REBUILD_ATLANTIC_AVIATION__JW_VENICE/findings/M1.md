### 2d. YTD rows (proposal)

- **YTD is cumulative:** each August YTD equals the sum of FCAST's
  January-August actual, to the cent, in both years (TOT_HTL revenue, Rooms,
  net and reserve; query `01c83102-030a-83ac-0003-4ff21c7aaeca`).
- **Adding YTD to MONTH would count January-July again.**
- **Proposal (Q-03):** stage every row with `PERIOD_TYPE`.
  - The five-part key is unchanged. MONTH and YTD rows of a line share a key

    addressable.

    beats YTD"); MONTH rows go to the streams.
  - Every YTD row is kept and counted, and none adds to MONTH.

`01c83106-030a-8402-0003-4ff21c7ba00a`):

**Proposal (Q-07):**

  adds `SOURCE_UNIT_SCALE` (1000 for dollar lines and, if confirmed, Gallons /
  Landings / Trips; 1 for MPG and the other ratios) and
  `SOURCE_UNIT_SCALE_SOURCE` = 'template header (000''s)'.
- **Transformation** sets `SOURCE_AMOUNT` (and `STAT_VALUE` where scaled) =
  staged value x scale. It is the one place the number changes, and it is a
  stated unit, not inference.
- **The reconcile** compares CLN x scale = XFRM = SEM per measure, and CLN =
  STG unscaled. So it still proves source = semantic, with the factor stated
  in the script.
- **The amount bridge (check 3)** states the factor per measure.
