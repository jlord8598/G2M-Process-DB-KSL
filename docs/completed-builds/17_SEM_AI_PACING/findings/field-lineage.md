# Field lineage (build 17): where each SEM_AI_PACING column comes from

| Column | Source |
|---|---|
| SITE | ALTERRA, BEAUMIER, THE_PIG, UNDER_CANVAS HOTEL_NAME; OUTRIGGER PROPERTY_NAME; KSL / PEREGRINE SITE_TAG; NEWBURY HOTEL_ID |
| SITE_NAME | KSL / PEREGRINE SITE_NAME; NEWBURY HOTEL_NAME; else null |
| SNAPSHOT_DATE / SNAPSHOT_SOURCE | SNAPSHOT_DATE (ALTERRA, OUTRIGGER, THE_PIG, UNDER_CANVAS); FILE_DATE::date (BEAUMIER, Q-02); AS_OF_DATE (KSL, PEREGRINE); REPORT_DATE or FILE_REPORT_DATE (NEWBURY, by table) |
| STAY_PERIOD_START / END / STAY_GRAIN | monthly lanes: date_trunc('month', STAY_MONTH) / STAY_MONTH (month-end as stored) / MONTH; NEWBURY STAY_DATE / DAY; KSL / PEREGRINE OCCUPANCY_DATE / DAY, EVENTS EVENT_DATE / EVENT (Q-04) |
| SEGMENT / SEGMENT_SOURCE | ALTERRA MARKET_SEGMENT_CATEGORY; BEAUMIER REPORT_TYPE; OUTRIGGER SEGMENT; THE_PIG, UNDER_CANVAS, NEWBURY MARKET_SEGMENT; KSL / PEREGRINE MARKET_SEGMENT_CODE |
| BOOKING_STATUS | KSL / PEREGRINE STATUS; else null |
| VANTAGE | the metric column's prefix (TODAY, STLY_DATE / DOW, FINAL_LY_*, ST2Y_*, TODAY_VS_*, CY_PACE, LY_PACE, FORECAST, BUDGET); BEAUMIER N_1..N_5 / CURRENT; NEWBURY DATA_TYPE or SCENARIO; KSL / PEREGRINE null |
| METRIC_NAME / VALUE | the unpivoted column name and its cell, cast to FLOAT, as stored |
| METRIC_UNIT / IS_ADDITIVE | the stop-1 mapping in the procedure (ROOMS, CURRENCY additive; RATE, RATIO, PERCENT_CHANGE not) |
| CURRENCY_CODE | currency / rate metrics: lane code (ALTERRA UNCONFIRMED, THE_PIG GBP, others USD), BEAUMIER the row's CURRENCY |
| IS_LATEST_SNAPSHOT | window max(SNAPSHOT_DATE) per site and source table within the lane block |
| SOURCE_TABLE | the stream's SOURCE_TABLE |
| SOURCE_LINE_KEY | SOURCE_FILE_PATH | SOURCE_ROW_NUMBER; null for KSL / PEREGRINE |
| ATTRIBUTES | object_construct_keep_null of every stream column except RUN_ID and the lane's numeric metric columns |
