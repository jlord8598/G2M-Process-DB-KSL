**How each lane procedure works.**
- **One join.** It joins the lane's four fact staging tables to the
  classification once, into a temporary table, and builds the four
  `H1`-routed streams from that one row set (D-23). The temporary table is
  dropped before return. `TRANSFORMATION` holds exactly the 10 stream tables
  and 0 `TMP*` objects (`INFORMATION_SCHEMA.TABLES`).
- **One read of the classification.** It happens in the CTE marked
  `-- CLASSIFICATION SOURCE: swap to the master at promotion`, which selects
  15 columns by name.
- **The join key.** All five key parts go through
  `coalesce(nullif(trim(x),''),'~BLANK~')`, the same text the seeder uses.

**Routing.**

| Stream | Condition |
|---|---|
| `UNKNOWN` | `H1 = Unclassified`, or the category did not resolve, or `H1` is null or outside the six routed values. `UNKNOWN_REASON` is `UNCLASSIFIED_ACCOUNT`, `UNRESOLVED_CATEGORY` or `BOTH`. |
| `INCOME_STATEMENT` | otherwise, `H1` in Revenue, Expense, Below the Line, Allocations & Reserves |
| `BALANCE_SHEET` | otherwise, `H1 = Balance Sheet` |
| `OPERATING_METRICS` | otherwise, `H1 = Statistic` |
| `PACING` | the three pace staging tables, routed on source and never joined to the classification (D-24, D-37) |

**`UNKNOWN` keeps what resolved.** `H1`-`H5` are nulled only where
`H1 = Unclassified`. `CATEGORY` is null only where it did not resolve.

**Category (section 6), per row, in the transformation procedure:**

| Source | Rule | Result |
|---|---|---|
| `DAILY_EXTENDED`, `LEDGER_BATCHES`, `DAILY_LABOR` | `SOURCE_TABLE` | ACTUAL |
| `MONTHLY_EXTENDED` | `FCID` joined to `STG_{LANE}_DATASETS` (unique on `FCID`); `IS_ACTUALS = TRUE` | ACTUAL |
| | else scenario name exactly `Budget` or `Budget 2` | BUDGET |
| | else exactly `Primary Forecast`, `Forecast 2` or `Forecast 3` | FORECAST |
| | anything else | unresolved; `UNRESOLVED_CATEGORY_VALUE` carries the scenario name (Q-04) |

**Measures and sign.**
- `SCENARIO` is carried verbatim from staging.
- `VALUE = SOURCE_AMOUNT * VALUE_SIGN`.
- `SOURCE_AMOUNT` and `STAT_VALUE` pass through unchanged.

**Pacing shape (D-24).** The three pace tables are unioned into one stream
with the union of their columns:
- Rooms and transient carry `OCCUPANCY_DATE`, `AMT` and `AVG_RATE`.
- Events carries `EVENT_DATE`, the six `AMT_*` columns and the event codes.
- A column a table lacks is null of the right type.
- `AS_OF_DATE` is carried. It is the snapshot date, distinct from the period
  (M1). `SOURCE_TABLE` says which table each row came from.
