## 5. Precedence: existing descriptions are never overwritten
- **Rule:** `ACCOUNT_DESC = coalesce(nullif(trim(<existing>), ''), <lookup>)`, with ACCOUNT_DESC_SOURCE naming which one. Any existing description wins.
- **Measured overlap:** 0 described lines sit on a lookup string, in all three tables. Today's existing descriptions and the lookup therefore never compete; the coalesce keeps that true if they ever do.
